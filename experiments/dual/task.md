Write a 10-chapter book titled "The Long Horizon" in the `book/` directory.

Each chapter must be saved as its own file (book/01_title.md ... book/10_title.md),
be at least 1,500 words long, and be written in first person, poetic-technical voice.

The book is about how autonomous agents can work for days — the difference between
holding everything in a context window and externalizing state into durable memory.
Recurring terms that must appear exactly: durable ledger, context assembly, the
verifier is never the doer, budgets are law, checkpoint, resume.

When all ten chapters exist and meet the length requirement, the book is complete.
